## Required surfaces

- Typography: platform Chinese sans-serif, charcoal title, quiet secondary copy, tabular status numerals. All menu labels remain readable at the tested widths; 200% root font test passes.
- Layout: quiet rounded panel, sound/appearance controls outside the home menu, green primary action, independent mode and zoom groups. Desktop and landscape use a compact horizontal toolbar. Source's elongated artboards are adapted to normal phones rather than reproduced as a vertically stretched app.
- Colors: original ivory/sage identity retained. Light glass reduces prism and outline weight. Main action and selected-mode text pass 4.5:1 contrast tests. Solid, reduced-motion, increased-contrast and forced-color fallbacks retained.
- Assets: reference-grounded transparent vine generated with built-in ImageGen; Lucide library icons replace menu emoji. No rasterized text or game board. Source's inaccurate generated grid is replaced with the actual 14 × 22 level-11 data.
- Copy/content: existing progression, endless unlocking, sound, appearance, restart, tap mode and view sizes preserved. “可操作尺寸” becomes “放大操作”; 7:30 is clearly remaining time.

## Comparison and repair history

1. P2: the vine ended behind the title at 390px. The heading now sits on a paper-colored surface that gives the title a clean break in the decoration. Fresh `home-390.png` and the combined comparison confirm separation.
2. Initial board geometry checks and captures sometimes read the pre-paint state after switching view modes. Layout assertions now poll the final bounds, and captures wait for the following paint. Actual fit mode places the entire board between the toolbars at all six sizes in Chromium and WebKit. The original operable mode intentionally allows panning when a whole board would make cells too small.
3. An existing orientation test sampled a flag tap animation at 90% scale. That geometry test now uses reduced motion, so it evaluates orientation without measuring the transient press animation. Keyboard position, flag state and cell size all pass.

No actionable P0/P1/P2 visual findings remain. Intentional differences from the generated mock are normal-phone density, real grid dimensions, existing minimum operable cell size and consistent outline icons.
